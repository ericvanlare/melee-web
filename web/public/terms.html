Save settings and local progress

Settings offers Everything unlocked and Personal progress. Everything unlocked starts from the supported original roster and stage baseline; changes during that session are discarded. Personal progress autosaves locally in this browser and can be exported or replaced with a compatible GameCube .gci save file. Local progress is not synchronized between devices or uploaded to the operator. Clearing this site's browser data can remove it, so use Export save for a backup.

Save files are checked against the supported USA Melee card format. A .gci identifies the USA game code, but does not itself record the disc revision; WebMelee only starts a selected disc after checking that it is the supported USA 1.02 copy. Loading a save while a game is active restarts that game so the original source routines can apply the profile before its menus load.

Ending a session

Eject commits a final Personal progress snapshot, unloads the native scene and reloads the page so the page and WebAssembly heaps and imported bytes can be retired. It does not clear the saved profile. Browser HTTP history, browser or graphics-driver caches, and saved keyboard preferences are separate from that page state. A reload can be required after an error.
