About & legal

Updated September 12, 2026. Work in progress.

WebMelee is an independent browser project for Super Smash Bros. Melee. When the player is available, it loads a compiled player and asks the visitor to select a supported local copy. It does not host a disc image, extracted game archive or user upload.

When the player is available, the current prototype supports a limited four-by-four slice: four supported fighters (Mario, Fox, Falco and Marth), four supported stages (Final Destination, Battlefield, Yoshi’s Story and Dream Land), local CPU opponents and desktop browsers with WebGPU. This is experimental work in progress; complete original-game accuracy, all content, mobile support, physical-controller coverage and full performance are not claimed.

Some CPU actions can currently stop the player. Use Restart to reset the page and select your local game again.

Local disc processing

When available, the player accepts an unmodified USA 1.02 ISO, GCM or CISO. It reads bounded local ranges, validates the GameCube image structure and checks the DOL SHA-1 against the expected USA 1.02 executable before preparing a fixed required-file inventory. The selected file and derived data remain in the page's native memory for the session. Eject unloads the scene, closes audio and reloads the page so the page and WebAssembly heaps and imported data can be retired. A browser or graphics-driver cache is outside that lifecycle.

What the public artifact contains

The player artifact contains project HTML, CSS and JavaScript, audio modules, an Emscripten-generated WebAssembly program and its data, and generated Aurora pipeline data. No retail disc image, extracted game archive, standalone game asset, screenshot, recording or repository source checkout is copied into the public artifact.

The generated pipeline data was captured from Aurora descriptors observed while rendering development game routes. Inspection found no raw texture, model, audio or disc bytes in the reviewed seed. Its status as generated renderer metadata and any rights needed to distribute it remain release-review questions.
