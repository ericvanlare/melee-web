What this public build contains

The public shell consists of original project HTML, CSS and a small JavaScript fullscreen control. It uses system fonts already available on your device. No font file, icon package, framework, third-party JavaScript package, image, audio, game executable or WebAssembly module is distributed in this build.

What remains outside this build

The development player uses recovered Melee source, Aurora, Emscripten and additional libraries. It also includes adaptations of Dolphin code and B0XX-style keyboard mappings. None of those components is loaded or shipped by this shell. Their licenses, source obligations and underlying rights require separate review before any playable distribution.

The recovered Melee source does not have an identified repository-wide license. A license on port code or compliance with a library license does not settle rights in recovered game code. This preview does not claim otherwise.
