# A3 browser-local native input sampling

**Source identified / Compiled / Browser exercised** for the bounded synthetic input and two-tick delay component.

The [portable receipt](../evidence/a3-browser-native-input-sampling-v1.json) binds the source/build producer, two retained failed browser attempts and their reduction, full-suite and Release-build results, native input witnesses, screenshots, WebGPU observations and owned cleanup for [issue #210](https://github.com/ericvanlare/melee-web/issues/210).

The probe used two headless Chrome peers on one Mac mini and the actual local Worker through direct Miniflare. Each page supplied a synthetic Gamepad; the browser sampled native `PADStatus` at the declared source cursor and passed the selected local port's existing 11-byte representation to the native peer. Alpha/port 0 contributed neutral, A, release, neutral at source/input cursors 0–3; beta/port 1 stayed neutral. The A sample retained the existing `BUTTONS.A` value. Poll serials increased for each new contribution, and the native input-component hash in every checksum record matched the expected captured bytes on both peers.

Input tick S was consumed at source tick S+2. Source ticks 0–1 remained neutral; source ticks 2–5 consumed input ticks 0–3 respectively. During a 120 ms withheld remote-input wait at source cursor 2, the local sample count stayed at three and its captured bytes and poll serial remained unchanged. Both peers completed six source steps and draws, six native checksums and six remote comparisons, acknowledged through input tick 3, and ended with identical checksum streams. The CSS screenshots were retained at source cursor 6; both pages reported cross-origin isolation and a WebGPU adapter, with no page errors.

The captures followed two failed browser attempts. The first stopped on an indexed native frame-push error at source tick 2; its older status snapshot cannot establish the first native cause. The second diagnostic run recorded that both peers' first native rejection was a repeated poll serial at source cursor 1; the later indexed-frame push error was secondary. An actual-clock/native reducer then exposed premature budget release after a remote wait. The reviewed fix keeps the scoped one-step budget through resume until all four local contributions are published, while retaining the default eight-step path and the serial guard. No historical samples are manufactured. The final capture ran on the rebased `e1bbfa9` producer after the full suite and ordinary Release runtime build passed.

The full unittest run completed 2,008 tests total, including 148 skipped and zero failures. The Release `runtime` build used default compiler jobs and its source commit matched the capture producer. The capture-owner, Worker and HTTP cleanup checks passed; all owned browser and service process identities/groups were absent, temporary Chrome profiles were removed, owned ports were free, and all 35 staged files remained unchanged.

This is synthetic, single-host, headless component evidence only. It does not establish physical or keyboard input, missing historical samples, input acquisition phase, latency, foreground timing, uninterrupted audio, Internet or two-machine play, WebRTC, pixel/PCM equivalence, performance or full-session accuracy. Issue #210's bounded experiment passed on this producer; its pull request still needs final-main CI and merge. Broader A3 acceptance remains open.
